
# Library Management System

A Library Management System developed in Python using Object-Oriented Programming (OOP).

## Features

- Add Book
- View Books
- Search Book
- Update Book
- Delete Book
- Menu Driven Program
- Uses Inheritance
- Uses Encapsulation

## Technologies

- Python
- OOP

## Concepts Used

- Classes & Objects
- Inheritance
- Encapsulation
- Constructors
- Exception Handling
- Loops
- Lists

## Project Structure

Librarysystem.py

## How to Run

```bash
python Librarysystem.py
```
